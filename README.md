# Kids Daily ⭐

A simple daily points app for Dior, Diane and Dylan. It is a single `index.html` file with no build step.

**Open it:** https://bornaxahadi.github.io/kids-daily/

## How the kids use it

- On the home screen, tap your own card.
- Tap a green **Good things** tile when you do something good (homework, cleaning up, reading, playing outside…) to earn points.
- Red **Oops things** tiles take points away (fighting, leaving a mess, too much YouTube…).
- Every tap waits for Dad to check it (⏳). Points only count after Dad confirms.
- Reach the daily target (12 points by default) to win 40 Robux the next morning.
- Use the **Roblox time** panel: tap **Start playing** when you begin and **Stop playing** when you finish. The timer counts your daily limit (2 hours normally, 3 hours on special days). Going over the limit costs points.
- **Progress** shows week and month charts plus Star of the Week and Star of the Month.

## For parents

- Tap **✅ Check** on the home screen and enter the PIN to review what the kids tapped today.
  - **Confirm**: the kid gets the points and **+1 trust point**.
  - **Deny**: no points.
  - **Change to…**: swap it to the right activity; those points count.
  - **Confirm all** approves everything waiting.
- Anything you tap yourself while Parent mode is open counts straight away.

- Tap **Parent** and enter the PIN. **The default PIN is `1234` — change it right away** in the PIN section.
- In Parent mode you can set the daily target, Roblox limits, mark special days, set Star prizes, mark Robux as given, and remove wrong taps (Remove buttons appear on each kid's page for 10 minutes).

## Where the points are saved

On this GitHub Pages site, points and settings are saved **in the browser on each device only** (localStorage). A tablet and a phone will each keep their own separate scores, and clearing browser data erases them.

The original Claude artifact link syncs points across all devices. Use that link if the kids share more than one device.
